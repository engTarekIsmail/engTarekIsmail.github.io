End-to-End ML Project

Bank Customer Churn Prediction

An end-to-end machine learning project that predicts whether a bank customer will churn, from data exploration and modeling to a deployed Streamlit web app.

Python Scikit-learn Streamlit EDA
1 / 4

Overview

The goal is to help banks proactively identify at-risk customers before they leave, so retention efforts can be targeted.

Dataset & Model

  • Data: BankChurners, 10,127 customers and 21 features, with about 83.9% existing and 16.1% attrited customers.
  • Model: Random Forest Classifier (100 trees, max depth 10) with balanced class weights to handle the imbalance.
  • Evaluation: 80/20 train-test split.

Key Insights

  • Transaction count and transaction amount are the strongest churn indicators.
  • Low activity and near-zero credit utilization are strongly linked to attrition.

Recommendations

Re-engagement campaigns

Target low-activity customers with re-engagement campaigns and transaction-based incentives.

Early-warning segment

Flag near-zero-utilization accounts as an early-warning segment for retention outreach.

Tools & Stack

Python Scikit-learn (Random Forest) Streamlit EDA
